# 西密乐方块世界（Similar Craft）

> 制作人：**武士芝士**


纯前端实现的 3D 体素沙盒（Minecraft 风格，游戏名：西密乐方块世界 / Similar Craft）：无限程序化世界、**会流动的水与岩浆**、**下界与末地两个维度**、**末地城与潜影贝**、**鞘翅滑翔**、生存与创造模式、合成/熔炼/附魔、红石电路、怪物与战斗、**末影龙 BOSS 战**、农业、昼夜与天气、存档与指令系统。所有贴图与音效都在代码里实时生成，唯一第三方文件是本地内置的 three.js。

## 怎么玩

最简单：**直接双击 `index.html`**，点「创建新世界」。（桌面上的 `Similar Craft/` 文件夹里就是这份游戏，双击里面的 `启动游戏.command` 即可）

如果浏览器（Safari / 部分 Firefox）禁止本地文件读写存档，用本地服务器打开：

```bash
cd 这个目录 && python3 -m http.server 8080   # 然后打开 http://localhost:8080/
```

macOS 也可以直接双击 `启动游戏.command`（自动起服务器并打开浏览器）。进入世界后**点击画面锁定鼠标**，`Esc` 暂停。

## 流体：水与岩浆（本次重点）

- **流动模型**：水源向外流 7 格、速度 4 格/秒；水流向下不衰减；液面按等级逐级降低，所以能看到水位的台阶。
- **无限水源**：两个水源夹一格（或一格水上方另有水源）会自动生成新水源，可以造无限水池；用空桶可以舀水源、用桶放置水源。
- **岩浆**：主世界与末地流 3 格（1.5 秒/格），下界流 7 格（0.5 秒/格），发光等级 15。下界里的水会立刻蒸发。
- **水火交融**：水碰岩浆源 → 黑曜石；两股流动液相遇 → 圆石；岩浆从上方浇在水上 → 石头。
- **水流推力**：水会推着玩家、生物、掉落物流动。
- **水流冲毁方块**：水会冲走火把、花草、枯木丛、农作物、红石线/拉杆/按钮/压力板/中继器、末地烛等，并掉落成物品；遇到火会把火浇灭。

## 三个维度

- **主世界**：无限地形（8 种生物群系）、洞穴与矿脉、树木花草、昼夜与雨雪；地下 x=-176, z=144 处有**要塞**（末地传送门房间，竖井通到地表，可用末影之眼或 `/locate stronghold` 找到）。
- **下界**：洞穴状地形、y=32 的岩浆海、天花板荧石簇、灵魂沙与砂砾湖岸、下界石英与岩浆块，以及横跨岩浆海的**下界要塞**长桥与塔楼（烈焰人出没）。没有昼夜与天气，只有昏暗红光，水会蒸发，坐标与主世界按 8:1 对应。
- **末地**：虚空中的末地石主岛、半径 42 的 10 根黑曜石柱（柱顶末影水晶）、中央返回传送门结构，以及外围的浮空小岛。
- **末地城**：外围空岛上会生成多层紫珀塔（紫珀块/紫珀柱/末地石砖/末地烛），塔顶宝箱里有钻石、绿宝石、附魔钻石装备，**有 60% 几率开出鞘翅**；每座城里有 2~3 只**潜影贝**守家（会发射追踪弹，被打时缩壳减伤，掉落潜影壳 → 可合成潜影盒）。

**传送门**：用黑曜石搭 4×5（或更大）的框，拿打火石点内侧面即可点燃；站进去 2.5 秒传送，自动在目标维度寻找或建造对应传送门（主世界↔下界坐标自动换算）。末地传送门要用末影之眼嵌满 8 个框架才会激活；末影之眼投掷后会朝要塞方向飞行指路。

## 末影龙 BOSS 战

进入末地后末影龙出现：绕着黑曜石柱盘旋、俯冲撞击玩家（顶部有 Boss 血条）。10 颗末影水晶会持续治疗它，必须先击碎（击碎时爆炸并对龙造成伤害）。击杀后中央返回传送门激活、出现龙蛋、获得大量经验并弹出通关画面，之后可继续游玩。

## 完整玩法清单

**世界生成**：大陆/丘陵/山脉/海洋/沙滩，8 种生物群系，洞穴（含地下岩浆湖），六种矿石矿脉，橡木/白桦/云杉/金合欢树、仙人掌、花草、雪原结冰水面；区块按距离流式加载，天光与火把光洪泛计算。

**生存**：生命/饥饿/氧气/摔落/岩浆/火焰/仙人掌/岩浆块伤害，饥饿值 >17 自动回血；五档工具材料（木石铁钻金）、三档盔甲、耐久与附魔台（效率/时运/锋利/耐久/保护/力量/击退）；床跳过夜晚。

**合成与加工**：工作台 3×3 + 背包 2×2 + 一键合成配方书；熔炉可离屏烧炼（矿石→锭、沙→玻璃、生肉→熟肉、原木→木炭）；箱子存储随存档保存；末影珍珠+烈焰粉→末影之眼；烈焰棒→烈焰粉。

**红石**：红石粉 15 级信号衰减、拉杆、按钮（1.2s 脉冲）、压力板、中继器（4 档延迟+信号放大）、红石灯（真实照明）、活塞推方块、TNT 爆炸连锁点燃。

**生物**：被动猪/牛/羊/鸡；敌对僵尸/骷髅/苦力怕/蜘蛛/末影人；下界烈焰人/恶魂/僵尸猪灵/岩浆怪；末地末影龙与末影水晶。夜晚或黑暗处刷怪，白天亡灵会燃烧，远离后消失。

**农业**：锄头开垦草地 → 种小麦 → 随机刻生长 → 收获小麦与种子 → 3 个小麦做面包。

**末地城 / 潜影贝 / 鞘翅**：末地城外岛上有紫珀塔与宝箱；潜影贝悬浮在原地发射追踪弹、受击缩壳减伤、掉落潜影壳；击败末影龙后去外围找城，开出**鞘翅**后从高处跳下按住空格即可滑翔（俯冲加速、缓慢下降、落地不摔伤）。潜影盒是可随身携带的 27 格储物（放在地上依然保留内容，打掉会连内容一起掉出来）。

**视角手感**：相机用 YXZ 顺序（先左右再上下），**怎么转都不会歪**；灵敏度是原版曲线，默认 140 ≈ **滑 100 像素转 29°**，设置滑杆 10~300 实时显示"每 100 像素转多少度"，嫌慢嫌快都能自己调。

**物品栏即时刷新**：捡东西、合成、吃东西、工具磨损后，快捷栏与生命/饥饿条会在下一帧立刻更新。

**吃东西怎么吃**：把面包 / 熟肉 / 苹果拿在手上，**按住鼠标右键约 1.3 秒**（屏幕下方会出现"进食中…"进度条），饱食度 +5 左右；**饱食度满了不会吃**（会有提示），掉饥饿了才吃得下。饱食度 > 17 会自动回血。

**这一轮修的（都是实际问题）**

- **物品名称不显示**：`#itemName` 元素上带着 `hidden` 类（`display:none`），所以无论怎么设透明度都看不见 —— 去掉了；现在切换快捷栏会在**对应那一格的上方**弹出一条小小的名字（12px 小标签：中文名 + 英文名 + 耐久）。
- **等不到天黑 / 没怪物**：默认一天 15 分钟太长 → 改成 **8 分钟**（设置里 180~2400 秒可调），进游戏就会提示"天黑会刷怪"；并且把刷怪频率调高（白天每 4 秒尝试刷动物、夜晚每 2.5 秒尝试刷怪，各 20~22 只上限）。自检实测：白天 24 只动物、夜晚 20 只怪物。
- **饱食度几乎不掉**：原来要累计 30 点疲劳才掉 1 格（原版是 4 点）→ 改成原版的 4 点；实测疾跑 30 秒掉约 4 格。
- **手持物品往右挪了一点**：方块/工具在屏幕右下角更靠边（0.54 而不是 0.38），空手手臂也跟着右移，不再挡准星。

**第一人称手上有物品了（含空手手臂）**

屏幕右下角显示你**当前拿在手上的东西**（原版那样）：方块 → 带贴图的小方块；工具/食物/箭 → 物品图标；**空手 → 一条手臂**（皮肤色 + 袖子）。切换快捷栏立刻更换；挖掘/攻击有挥动动画，走路轻微浮动。

> 修 bug 记录：之前手持模型挂在相机上，但**相机从来没被加进场景**，three.js 只渲染场景图里的对象，所以怎么都不显示。现在手持模型挂在场景里、每帧按相机世界矩阵摆放（自检用像素对比验证：手持铁镐在右下角有 1879 个可见像素、空手手臂 515 个像素）。

**修掉一个自己引入的 bug**

上一版虚拟光标的拦截条件写宽了 —— 正常游戏时它也会拦截鼠标滚轮和点击，导致**滚轮切换物品失灵**（所以物品名也不弹了）。现在虚拟光标**只在"有界面打开"时接管鼠标**，正常游戏时滚轮切换、左右键挖掘放置全部照常；自检里加了"滚轮必须能切换物品并弹出名称""没有界面时虚拟光标不许接管"这两条。

**聊天与 HUD 不再糊在屏幕上**

- 聊天消息（系统提示、指令回显）的完整流程：**正常显示 → 停留 9 秒 → 1 秒淡出 → 从页面上消失**，最多同时显示 8 条；按 `T` 打开聊天框时消息会一直保留，关掉聊天框后重新开始 9 秒计时（旧版本这里被每帧强制设成 15% 透明度，所以消息会半透明地永远挂在屏幕上）
- 右侧「新手目标」面板 **20 秒无操作自动变淡**，按 `J` 可以随时收起/展开，完成目标时会自动亮起

**鼠标锁定（进游戏 / 退出容器界面自动锁）**

**现在采用和原版一样的做法：玩游戏时鼠标一直保持锁定，界面里用"虚拟光标"操作**（鼠标不会被放开）。所以：
- 打开/关闭背包、工作台、熔炉、箱子、附魔台、潜影盒、创造物品栏 —— **全程不需要重新锁定**
- 按 `E` 或 `Esc` 关闭界面都是**直接继续游戏**，不会再出现"点击继续"的步骤，也绕开了浏览器"按过 Esc 后拒绝锁鼠标"的限制
- 暂停菜单、设置、成就、帮助、死亡、通关界面同样用虚拟光标（鼠标仍是锁定的，关掉后立刻能转视角）

- 按 `E` 关闭任何容器界面（背包、工作台、熔炉、箱子、附魔台、潜影盒、创造物品栏）→ **立刻锁回鼠标，直接继续游戏**
- 按 `Esc` 关闭界面 → Chrome 对 Esc 后的指针锁有冷却会拒绝请求，这时**不再硬锁**，只会在 1.2 秒后于屏幕**底部**显示一个小胶囊提示"点击画面即可继续操作鼠标"，点一下或按任意键立刻锁上并消失（不会遮住画面）
- 主菜单、暂停、设置、成就、死亡、通关等弹窗打开时**不会**锁鼠标；关闭后（返回游戏/重生）自动锁回
- 任何一次点击/按键也都会尝试锁回（浏览器要求由用户手势触发）

**存档保护**

- 主菜单会显示**上次存档的详细信息**：维度、第几天、时间、坐标、物品件数、种子 —— 一眼就能看出"继续"会回到哪里。
- 点「创建新世界」如果已有存档，会**弹窗确认**（避免手滑把存档覆盖掉，这正是"物品栏没了"最常见的原因），并且覆盖前会自动留一份**备份**，菜单里可以「恢复备份存档」。
- 每次保存都会把上一份存档另存为备份。
- 自动存档间隔从 60 秒缩短到 **30 秒**，另外关页面/切后台时立即存一次。
- 自检里验证了完整物品栏的存取回环：热键栏/背包/装备栏/附魔/选中槽位/生命饥饿都会还原。

掉落物以前是一个方盒子贴物品图标 —— 图标的透明背景在盒子上变成黑块，看着很怪。现在改成**一张平面 + 透明裁剪，每帧自动转向你**（看起来就是一张物品图，不会出现交叉的两张）；自检里会检查"只有一张平面、必须朝向玩家、画面里真的能看到、没有大片纯黑"。

**方块贴图不显示（白色方块）——根因**

方块着色器里只用了贴图的 alpha，**忘了乘以贴图本身的颜色**：`vec3 c = vColor * 光照`。所以所有方块都渲染成"顶点色 × 光照"的灰白色，只有草/树叶因为有生物群系染色才显得绿 —— 这就是你看到的"白色方块"。修复后：`c = vColor * tex.rgb * 光照`，工作台是木色、石头是灰色、沙子是沙色（自检里用像素统计卡死：工作台必须有 300+ 个木色像素，石头不能是木色）。

**存档会丢位置 / 回不到上次的地方 ——根因**

1. 存档**不记录维度**：在下界/末地存的档，读回来会把坐标套用到主世界，位置完全不对 → 现在存档记录 `dimension`，读档先切回该维度再放玩家。
2. 读档时用"地形高度"覆盖了玩家 Y 坐标 → 现在只在卡进方块里时才往上顶。
3. **存档体积会涨到 39MB 撑爆浏览器 5MB 配额，保存静默失败**（于是你读到的永远是旧档）：每放一格都往状态表里记一条，水流过的每一格也记（测试里 65 万条）。现在：
   - 方块改动按区块压成 base64，**每格仅 3 字节**（原来 JSON 文本约 25 字节/格）
   - 流体状态单独存、按距离**上限 4 万格**
   - 默认状态（水源、0 级红石线、空箱子、没长的作物）不写进存档
   - 万一还是超配额：自动丢弃远处（400→50 格外）的改动记录并提示，保证附近建筑不丢
   - 关页面/切后台时**立即存档**（`beforeunload` / `pagehide` / `visibilitychange`），不再只靠 60 秒自动存档
4. 另外补上**存取档回环自检**：在下界 12.5/41.25/-33.75 存档 → 读档后必须回到下界同一位置且物品完好。

**放置方块不再隐身（三个 bug 一起修掉）**

1. 区块网格只渲染生成时记录的 `[minY, maxY]` 范围 → **放在地表之上的方块（草地上的工作台、你盖的墙）根本不生成网格**；现在放置/破坏都会同步扩展范围。
2. 每放一个方块会排队一次光照重算，而每帧只处理 1 个 → 造一个石台就排 200+ 个任务，**新放的方块几十帧都轮不到重建**；现在任务按坐标去重、上限 4096、每帧处理 6 个，并且**放置的瞬间就把区块标脏重建**。
3. 区块网格曾经关掉了 `matrixAutoUpdate`，导致**重建出来的网格算不出世界矩阵、模型跑到世界原点**（眼前就只剩天空/雾＝看起来"白色"）；已改回自动更新并主动标脏世界矩阵。

**物品名称提示（像原版）**：滚轮或按 `1`~`9` 切换物品时，会在**快捷栏里那一格的正上方**弹出一个小小的名字标签（中文名 + 英文名，工具/盔甲还带耐久），不会在两格之间乱飘；拾取到新物品、切换到新物品时也会弹。显示 2 秒后淡出，`Shift` 之类不改变选中格的操作不会让标签跑位。

**贴图自检**：聊天框输入 `/rendercheck`，游戏会在你正前方放一个工作台、渲染一帧、采样准星处的像素并告诉你结果（正常会显示"木色正常 ✓"，并给出 RGB、方块在网格里的顶点数、准星射线命中的方块）。贴图缺失时会画成**洋红黑格**，一眼就能看出是贴图问题。

**贴图**：所有方块/物品贴图仍是代码生成（原版贴图有版权，不能打包分发），但配色参考了 CC0 的 "16x16 Block Texture Set"（ARoachIFoundOnMyPillow, CC0），重画了草方块（带锯齿草边）、石头（大块斑驳）、圆石（圆润石块+勾缝）、木板（错缝+木节）、原木（树皮沟壑+年轮）、树叶、沙子、泥土等。

**其他**：昼夜循环（默认 15 分钟一天）、太阳/月亮/星空/云、雨雪与雷电；WebAudio 合成音效与背景音乐；29 个成就 + 10 条新手目标；小地图（地形/生物/掉落物/朝向）；自动存档与种子复现。

## 自检

打开 `index.html?selftest=1`（加 `&autostart=1` 自动进入世界）会跑 **83 项**自动化测试：渲染三角形数、三个维度的画面像素采样、区块网格、方块读写、射线检测、挖掘掉落、各类合成（含空格图案）、熔炼、红石导通与贴图切换、爆炸、光照、天光、生物 AI、弓箭、作物、附魔、各 UI 界面、指令、存档与完整读档重开、模拟行走/跳跃/挖掘/放置/攻击，以及水流扩散 7 格、无限水源、岩浆 3/7 格、黑曜石/圆石/石头三种水火反应、水流冲毁小方块、下界地形与要塞、传送门点燃与往返传送、末地地形、末影龙与末影水晶、末地传送门激活、维度隔离、**末地城结构与战利品、潜影贝 AI（悬浮/追踪弹/缩壳/掉落）、潜影盒存内容、鞘翅滑翔与无摔落伤害、视角转速与不歪、右键各类交互方块能开界面、方块图标与方块本身都使用自己的贴图（工作台必须是木色）、拾取后物品栏即时刷新、工作台手动摆放合成、吃东西、放置在地表之上的方块能生成网格、切换物品弹出名称、/rendercheck 贴图自检、存档读取后维度/位置/物品全部还原、掉落物是单张平面、朝向玩家且画面可见**等。结果会写到控制台和页面里的 `#bootlog`。

`index.html?autostart=1&soak=60` 会跑 60 秒（3600 帧）压力测试：夜晚刷怪 + 玩家自动移动 + 随机挖掘丢弃，并且每 20 秒自动切换一次维度，统计生物峰值、流体队列与异常数量。

## 开发与发布约定

- **主开发目录就是桌面上的这个文件夹**（`~/Desktop/Similar Craft`），改代码、跑自检都直接在这里做。
- 打包：在同级目录生成 `~/Desktop/Similar Craft.zip`。用 `git archive --format=zip --prefix="Similar Craft/" -o "../Similar Craft.zip" HEAD`（只打包 git 跟踪的文件，不会把 `.git` 和 `.DS_Store` 装进去），解压后顶层就是 `Similar Craft/`。
- 远程仓库：<https://github.com/X4CE-Organization/Similar-Craft>，分支 **main**；每次改完都要 commit 并 push。
- 双击 `推送更新.command` 可以一键提交并推送（也可以直接 `git add -A && git commit -m "..." && git push origin main`）。
- 自检命令：`index.html?autostart=1&selftest=1`（83 项）与 `index.html?autostart=1&soak=60`（压力测试）。

## 已知取舍

- 没有多人联机。
- 末地没有末地船/末地折跃门与潜影贝的复制行为；潜影盒不做染色变体。
- 水流冲毁覆盖的是“小方块”一类（火把、花草、作物、红石元件、末地烛、火），石头木头这类方块不会被水冲走（与原版一致）。
- 世界存档保存在浏览器 localStorage（约 5MB），大量改动可能写满，可在设置里删除存档重开。
